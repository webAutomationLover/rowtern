# Rowtern

Rowtern is a Chrome extension that snaps a web page into a spreadsheet.

Official website: https://www.rowtern.com/

Chrome Web Store: https://chromewebstore.google.com/detail/capture-web-table/eafdodlfkbaacdomgfjcjldigmbiipmc

## Spreadsheet workflow

1. Install the extension.
2. Open a list, table, or catalog you already use.
3. Snap the page with 1-Click or the Wizard.
4. Review the columns and export to Excel.

Practice on the Playground does not use plan quota: https://www.rowtern.com/playground

This repository is a lightweight public note for Rowtern product information and support links. It does not contain the extension source code.
